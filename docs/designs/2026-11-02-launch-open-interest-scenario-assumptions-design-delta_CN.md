## 1. 目标和变更边界

在 OI 历史信息截止时间或实际发布时间无法证实时，允许基于**明确的假设情景**描述 OI 与后续价格的历史关联，而不是将假设伪装成事实。此研究用于筛选后续假设，不证明历史可预测性、因果、可交易收益或风险可控；不能仅因各情景结果一致就晋级。

本文拟替换父 Design §3 的 OI 信息时间门禁、观察时点及相应敏感性规则，以及 §5 `INV-03`、`INV-06` 和 §6 中与其直接冲突的部分，精确覆盖关系见 §3.1；父 Design 其他样本、Parent、输入完整性和权限边界继续有效。只有本 Delta 经批准后，上述替换才生效。此前旧数据和极端案例已被观察，本文不是独立预注册或样本外验证。

## 2. 固定情景与时间规则

`label` 是历史数据标签；`information_time` 和 `available_time` 的真实值在缺少证据时均为未知。对每个标签 T，先假定信息最晚截止于 `T+信息偏移`，再假定最早可用于观察的时间为 `T+信息偏移+发布余量`：

| 情景 | 信息偏移 | 发布余量 | 假定可用时刻 | 作用 |
| --- | ---: | ---: | --- | --- |
| A | 0m | 5m | `T+5m` | 较乐观假设 |
| B | 5m | 5m | `T+10m` | 较保守假设，主描述情景 |
| C | 10m | 5m | `T+15m` | 更严格压力情景 |

偏移和余量都是研究假设，并非来源证明的最大延迟；C 不保证真实可得。每条记录需明确输出假定时刻及场景，不能将其标为实测时间或可信上界。若存在与这些假设相冲突的已核实来源事实，停止受影响数据比较并报告，不屏蔽证据。真实无歧义的已核实时间可作为事实单独记录，但不覆盖情景结果。

**观察点：** 所有情景统一 `D=T0+25m`，不根据结果调整。理由：若继续采用父 Design 的 `D=T0+15m`，B 要求 `label <= T0+5m`，在 T0 不与自然五分钟网格精确重合时通常不足以取得两个 T0 后、间隔五分钟的标签；C 则不足以形成两点。将 D 固定为 25m 是让较保守情景有形成两点的数学空间，不是声称数据必然覆盖、可实时获得或 25 分钟更优。该时点变更将改变目标窗口和样本，不得与旧 D 结果直接当成同口径比较。若历史包不能覆盖新终点则保留缺口，不得因此调整 D。

**OI 两点：** 每个情景独立在同合约中选取满足 `T0 <= label` 且该情景 `假定可用时刻 <= D` 的最新标签 `L1`，再取严格为 `L1-5m` 的 `L0`；`L0 >= T0` 且也须满足相同情景可用约束。先选 L1 再验 L0；缺前驱、重复标签、无效数量、单位不一致或无足够标签时缺失，不回退找更早完整对、不插值。原始 `sum_open_interest` 数量保持不变，不将数量变化称为资金净流入或多空方向。

分别记录标签、原值、情景下假定信息截止与可用时刻、距 D 的年龄和缺失原因。不能把假设时刻写入原始归档、表示为真实接收时间或声称对应可成交信号。

**开盘网格对照：** 父 Design 的 `L0=floor_5m(T0)`、`L1=L0+5m` 保留，但各情景分别应用上述假定可用约束及同样的身份、数量检查；允许 L0 标签早于 T0，记录其与 T0 及计划上线时间的差值，不推断它是初始持仓。只作独立的事后探索对照，不改变主分组，不只选暴涨事件。

**价格基线、基差及结果：** 沿用父 Design 对 `[T0,D)`、mark/index 产品映射与 `D-1m` 闭合条件、`[D,D+5s]` 参考成交、entry 后 15m 终点和路径的定义，只将 D 替换为上述新观察点。成交价是描述性参考而非真实报价或成交；基差映射无可核验来源则缺失，不影响 OI 样本资格。记录单事件时间和跨日日期；缺 entry/endpoint 或 required package 均按缺口报告。

## 3. 汇总、验证与结论

- 保持父 Design 的 Universe、`(parent_article_id, symbol)` 身份、按 `listing_regime` 分开和 Parent 聚类。每个情景独立报告 Universe、OI 两点覆盖、完整 child/Parent、缺口和时点年龄；不混用分母。
- A/B/C 各自按本机制完整样本的 OI 变化事后中位数分组，`>` high、`<=` low；分别报告 child 和 Parent 组数及 `terminal_return` 均值差，空组为 `null`。B 另按父 Design 汇报 terminal、MAE/MFE 分布及逐 Parent 剔除敏感性；A/C 不要求额外 LOO。网格对照单列，不混入主分析。
- 同时列出各情景完整样本的重合数和差异；覆盖改变时不得把组间结果变化直接归因于延迟。各情景方向不一致、样本过少或结果受单个 Parent 主导时说明局限。若 B/C 无法形成有效样本，报告 `evidence_insufficient`，不得自动后移 D 或删去不利情景。
- `historical_scenario_only` 是结果解释标签：输出可提示后续研究假设或 `evidence_insufficient`，不得声称 PIT 已验证、因果、净 PnL、胜率、`alpha_validated` 或交易准入。PIT 历史事实验证与未来事件观察仍需独立证据；不虚构缺失数据或样本外结果。
- 实施测试须用独立手算覆盖三个假定可用时刻及等号边界、同一 D 下各自两点和无前驱、T0 非网格对齐、跨日、Parent 分组与空组、entry/endpoint；并检查报告中每个情景的假设和分母。纯逻辑可用合成数据；真实上游兼容仍按既有契约与单独授权验证。

### 3.1 父 Design 不变量与旧 Plan 的精确覆盖

本 Delta 获批准后，对本次 `historical_scenario_only` 研究，父 Design §5 对应条款由以下文本替换；其他未冲突不变量不变：

- **替换 `INV-03`：** 固定 D 和 A/B/C 假设，分别验证所选标签及假定可用时刻的先后关系，不使用超出情景时间约束的记录；记录实际标签、情景假设、假定时刻及缺口。真实 `information_time` / `available_time` 未获证实时保持未知，不能把情景先后关系称为已验证 PIT 或断言实际没有未来数据。已核实的来源事实若与某情景假设冲突，停止受影响情景的数据比较并报告冲突；不得屏蔽事实或改写假设继续。
- **替换 `INV-06`：** 独立手算测试覆盖 A/B/C 假定时间、OI 两点选择与无前驱、等号边界、网格对照、自然分钟与产品映射、基差缺失不影响 OI、5 秒 entry/1 秒 endpoint、跨日、路径、Parent 平局与空组，并验证结果标签、情景假设及分母。假设偏移测试仅证明按假设计算正确，不能称为真实来源时效或历史 PIT 验证；真实上游兼容仍须按适用契约使用权威来源并另获必要授权。纯计算可使用合成样例；不默认新增独立 Verifier、封树或 Recorder。
- **父 §6 时间规则的适用范围：** 无法确认真实信息截止时间或可信上界时，仍不得作事实型 PIT、历史实际领先或实时可得的声明；但不因此禁止符合本 Delta、明确标记 `historical_scenario_only` 的假设情景计算。若已核实事实与情景冲突，按上述 `INV-03` 停止受影响比较；缺口与未知不得伪装成实证通过。
- **后续 Plan 绑定：** 原 Plan 的 Task 1、Task 3 等“无可信真实上界即不计算”的旧实施和测试要求不自动变更，其批准也不授权按新语义实施。后续须以**实际获批的本 Delta 路径及 SHA-256**和父 Design 为依据，形成并经独立审查、用户批准的修订 Plan，重新映射所有受影响任务与测试；不得将假设偏移填入或标记为已证实的真实截止上界。实际历史消费、网络与运行仍按适用契约另行授权。
