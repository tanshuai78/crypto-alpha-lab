## 1. 一页结论与投入取舍

**只问一个问题：在相同样本、相同预测时点和相同结果窗口下，“持续净卖出且先前下跌时的价格减速”这一交互，是否比已经包含普通价格、成交失衡、波动及活跃度的基准提供额外预测信息？**

只运行 S1、两个固定模型和一个候选交互。不搜索窗口、阈值、子组或模型；不做交易回测。若基准无法公平拟合、交互不可识别或没有观察到改善，就交付现状，不自动扩样或调参。

- 已确认：预审有 51 个 child / 41 个 Parent 的窗口记录；不等于有 41 个相互独立的市场环境，也不等于已确认可估计。
- 未检验：价格响应变化、未来收益增量、真实可成交性及成本后收益。H1 尚未证伪，也未获得这些层面的支持。
- 机制假设：急于成交者与承担库存/逆向选择风险的一方可能形成不同的成交压力—价格响应；现有数据不能识别参与者身份或直接确认盘口吸收。
- 机会与投入：旧样本仅作探索。11-10 预审在其特定范围内仅确认一个后续候选，不能外推为全市场频率；独立新事件验证的速度和价值仍未知。
- 较小替代：仅画价格与卖压图不能回答新增信息问题；本规范比图形描述多两个固定回归，但不引入扫描器、通用回测平台或新采集链。
- 更大替代暂不做：成熟币扩样、S2、非线性模型、盘口采集、交易规则和完整收益路径研究。

本规范冻结的是**一次候选检验方法**，不是宣称这些参数最优。以后可凭新依据修订并记录新版本，但不能在同一次看过结果后改参数、覆盖旧尝试再冒充事前方案。原预审预算不自动续期；新增实施与运行预算见 §8。

## 3. 唯一时间口径与变量

### 3.1 S1 与边界价格

T0 沿用已核验的首笔成交锚点及原 300,000ms 最大延迟规则，不优化锚点。S1 为：缓冲 `[0,5m)`、W1 `[5m,15m)`、W2 `[15m,25m)`，均相对 T0；决策时点 D=T0+25m，唯一结果终点 E=T0+40m。S2 本轮不运行。

该尺度的依据是已核验覆盖、等长 W1/W2 可直接比较和较小工程增量，不是收益择优或已证实的最优持有时间。

- `P(b-)`：物理成交顺序中最后一笔 `timestamp < b` 的价格；相同时间戳按已核验的 agg_trade_id 顺序取最后一笔。不使用线性插值或 b 之后的成交。
- W1/W2 的价格收益分别为 `r1=ln(P(T0+15m-)/P(T0+5m-))`、`r2=ln(P(D-)/P(T0+15m-))`。
- 结果价格 `P(E)` 取最后一笔 `timestamp <= E` 的成交；主标签 `y=ln(P(E)/P(D-))`。它是历史参考价收益，不是可成交收益；没有暗中加入“零滑点即可成交”的假设。
- 每个端点输出实际成交时间、ID、价格与距边界的年龄。特征仅消费 `timestamp < D`；未来区域只用于 y 和已声明的覆盖诊断，不回流特征或训练集处理。
- P(5m-)、P(15m-)、P(D-) 必须分别落在缓冲窗、W1、W2；RV 分钟边界的价格须落在其左侧一分钟内；结果端点必须落在 `[D,E]`。缺失、非正/非有限价格或与预审覆盖矛盾时停止；不以任意 epsilon、前向越界取价或结果相关删样本兜底。
- 不新增秒级陈旧阈值。端点年龄完整披露；这不证明报价新鲜或实时可交易。若年龄使解释不能成立，本轮结论为受限/不足，不事后调整端点。

### 3.2 唯一候选交互

每个 Wk 内，B 为主动买入名义金额、A 为主动卖出名义金额，`V=B+A`，`s=(A-B)/V`；V 必须为正。`is_buyer_maker=True` 对应主动卖出，金额按 price×quantity 累计。

定义：

```text
d = r2 - r1
S = 1[s1 > 0 and s2 > 0 and r1 < 0]
X = S * d
```

S=1 表示两段净卖出且前段价格下跌；此时 d>0 表示后段下跌减速或转为上涨，d<0 表示进一步下行。这是一种待检验的代理，不是对“真实吸收”的识别。0 只是净卖出/下跌的定义边界，不是通过收益优化出的强度阈值。

不使用 `r/Q` 或 `Q2/Q1` 作为候选，不冻结预审的 2%/5% 描述切点。不额外增加买方镜像、第二交互、强卖子组或突破触发器。

### 3.3 固定基准 M0 与扩展 M1

| 设计列 | 定义与保留理由 |
| --- | --- |
| 截距 | 两模型都包含 |
| r2、d | 最近收益与价格减速；已能线性重构 r1，不再重复加入 r1 |
| R、Z | `R=1[r1<0]`、`Z=R*d`；价格独有的“前段下跌”及其减速交互，避免 X 仅因获得非线性的价格减速信息而取胜 |
| s1、s2 | 普通成交失衡，避免把旧方向指标包装成新增信息 |
| S | 候选状态主效应，防止交互只靠状态平均差异取胜 |
| RV | `[T0+5m,D)` 的 20 个一分钟收益平方和开根号；每个分钟边界均用 `P(b-)`，共 21 个价格。1m 是固定归约粒度，不声称最优 |
| L | `ln(V1+V2)`，V 的单位固定为 USDT；控制跨币种活动规模 |
| H | `ln(V2/V1)`；控制活动共同冷却；V1、V2>0，不除以净流 |

M0 共 11 列（截距+10项），M1 只增加 X，共 12 列。R/Z 不是第二个待选 Alpha，而是保护基准的价格对照；省掉它们虽能少两列，却可能把普通价格非线性误归于卖压交互。若这些必要控制超出样本承载范围，应暂停，而不是弱化基准。

两者均为带截距的加权 OLS；不搜索正则化、截断、树模型或其他超参数。每个训练 Parent 内 child 权重为 `1/n_child`，随后整体归一化。

连续列只使用当折训练集的 Parent 等权均值/标准差做标准化：归一化权重 w 后，`mu=sum(w*x)`，`sd=sqrt(sum(w*(x-mu)^2))`，不加 epsilon；R/S 保持 0/1。先按原始定义构造 Z/X，再分别按训练集标准化。不得用全样本归一化、标签或未来事件确定任何预处理。报告 X 系数须换回原始尺度；H1 预期其方向为正。

基准覆盖价格、普通失衡、波动和活动，不保证已经排除所有竞争解释。即使 M1 改善，也只能归于这个明确交互在此基准下的结果，不能证明因果、机构承接或普遍方向预测。

## 4. 只做一次时间前推比较

### 4.1 分组与训练起点

1. 按 Parent 分组。共享决策时点 D 所在 UTC 日的 Parent 合并为不可拆评价块；若 Parent 跨多个决策日，则连同其触及的日组一并合并。不拆 child、不随机打散、不创建通用分组框架。
2. 评价块按最早 D 排序。某块只使用更早且所有 child 的结果终点 E 严格早于该块最早 D 的已完成 Parent 训练；当前块和后续数据不得进入训练。
3. 从最早满足下述**特征侧**条件的块起评价，此后使用扩展窗口。此前块标记 `warmup`，不作为预测成功样本。不得按标签表现选择训练起点。
4. 训练 Parent 数须大于 M1 列数 12；这是避免用多 child 制造拟合自由度的最低保护，不是统计充分性或机会频率标准。
5. 两设计矩阵须满列秩，且 X 增加一维；除截距外的必要列在训练集不得为常数。标准化后对 `diag(sqrt(w))*X_train` 使用 float64 SVD，秩容差为 `eps64 * max(n_rows,n_cols) * largest_singular_value`；OLS 使用同一相对截断规则，不加正则。记录秩、奇异值/条件数；不为得到结果调容差或使用秩亏伪逆硬拟合。
6. 条件仅在 warmup 阶段用于确定起点。评价开始后若出现身份、数据、秩或数值错误则停止，不能跳过不利块、临时删控制变量、改 Ridge 或截断极端预测。若始终无合格起点，结果为 `evidence_insufficient`，不进入模型比较。

这些是本次固定参数化的保守拟合保护，不是最小样本量定理。若因必要状态缺乏变化、冗余或精度问题而停止，须交付具体矩阵证据；不能据此宣称广义 H1 不可检验，也不能默默改为另一组基准。

两模型的训练集、评价集、权重、标签、端点和标准化规则必须完全一致。必须报告完整 53/42 源分母、51/41 计算集、warmup 和实际评价 Parent/child/块数量，不能把 41 全部称为样本外预测数。

### 4.2 主要指标与必要诊断

对每个被评价 Parent j，先对其 child 误差平方取平均，得到 `L0_j`、`L1_j`；再令 `delta_j=L0_j-L1_j`。唯一主要指标是所有被评价 Parent 等权的 `Delta=mean(delta_j)`，正值表示 M1 误差较小。

- 同时报 M0/M1 的 MSE、RMSE，以及 `G=1-MSE1/MSE0`。MSE0=0 时 G=null，不用 epsilon；这不是手续费覆盖或资金收益率，也不与旧 OI/基差研究在不同标签和评价方法下的改善百分比直接比较。
- 次要诊断固定为逐 Parent 绝对误差、delta 分布、真实 y 分布及尾部观测、每折原尺度 X 系数及极端预测。不把 MAE、正确率、某子组或某个日期替换成主指标。
- 披露正/负贡献总量、贡献最大的 Parent 和 UTC 日块。对每个 Parent/块，从**已经算出的固定贡献**中逐一剔除并报告剩余 Delta 的全范围；不重新拟合，不删除后重定义主结果。
- 若某次剔除后无剩余评价 Parent，值为 null，不能满足正结果分流条件。X 系数中位数按每个评价块一次计入，不按 child 重复计数。
- 上述剔除范围不是 Jackknife 置信区间，也不能证明训练样本影响稳健。模型系数符号序列和贡献分布用于表达不确定性，不声称事件必然相互独立。

本最小实验不做置乱显著性检验、Bootstrap CI 或 p 值，不以未经校准的区间冒充统计精度。`minimum_economically_meaningful_gain=null`：目前没有策略/成本依据，Plan 不得随意补一个数。本阶段不能给出“精度足以排除有意义 Alpha”的科学证伪结论。

| 观察结果 | 唯一允许的资源判断与结论边界 |
| --- | --- |
| 数据/身份/公开 loader 不通过 | `blocked`；停止，不改历史哈希、不换根、不自行修复重跑 |

以上 0 是模型比较/方向的自然参照，不是 Alpha 显著性、收益率或交易阈值；逐一剔除条件只用于防止单一评价单位决定后续投入，不要求每个事件盈利或每个预测都改善。未通过敏感性条件不证明所有肥尾型策略无效。

- 预审中的 Parent 累积/卖压公式可复用或按公开接口局部适配。不能仅靠 import 宣称复用，也不为“薄脚本”把逻辑挪成新框架。

- 数值进程使用上表现有项目 venv/NumPy，只接受本次已校验的特征表；仅导入标准库和 NumPy，不导入 `configs`、`research`、`src` 或任何归档 reader，不打开 J-A/J-B 树、原始 ZIP/账本。其 cwd 和输出位于仓外，不写主仓或依赖缓存。
- 数值进程在拟合前校验表的 SHA、实验身份、键/列/有限性、名单及分母，并复核特征代数；不能借“读了派生表”绕过本实验的消费批准。
- Plan 固定解释器与 NumPy 版本、实际模块来源及本规范求解规则；不安装/升级依赖，不自写 QR/SVD 库，也不把主仓 site-packages 塞进历史读取进程的 sys.path。任一现有环境失效先停止。

### 6.2 最小交付与验证

仅需：child 特征/标签及端点表、当折预测/权重与训练身份、Parent 损失/固定贡献、汇总 JSON 和人工报告。具体合并方式与仓外路径由 Plan 白名单确定，不建立正式 Stage 或新生产收据。

这些是可重算探索产物。特征表的消费者仅为本次获准数值进程及人工复核；预测/损失/汇总只供人工复核，不授予其他机器消费者资格。结构校验须覆盖键/类型、有限性、身份、分组与分母守恒；独立语义证据须包含手算向量和实际输出重算，而不是生产者/loader 同一公式自证。

必要测试只覆盖本规范的实质边界：成交方向/端点半开区间、D 前后隔离、X/S/d 手算、基准张成空间/秩、训练侧标准化、Parent 等权/同日隔离、固定贡献剔除、失败不覆盖，以及两个进程的导入/输入隔离。应证明只改变 y 不改变 warmup/名单/分组，评价块的 y 不影响该块预测；这属于隔离反例，不是置乱显著性检验。内部纯逻辑可合成；真实跨模块正向兼容必须走 canonical 上游/公开 strict loader，不能用桩冒充实源通过。

不为新探索结果新增独立 Schema Verifier、锁/恢复状态机或完整 Rule 17 profile；J-A 已有冻结 profile、授权原件和 strict-loader 义务不变。一次输出须使用新目录，错误返回非零，不让部分文件冒充完成；日志如实记录实际读取与附带的全根校验。
