## 1. 目标、决策价值与范围取舍

唯一问题：在预先指定的五个成熟现货交易对上，两个既有固定信号分别触发后，四小时参考价收益的**样本均值**及相对简单对照的均值增量如何，是否值得承担一次后续独立验证的成本？

这里的“增量”只相对于 §5 的明确对照，不是因果效应，也不宣称已经排除了所有价格动量、波动率或市场风险解释。没有正向结果也可以完成实验。

| 选择 | 本次决定与理由 |
| --- | --- |
| 全市场动态历史币池 | 暂不建设；发现目录不等于恢复历史资格，分类、退市与正文版本处理的成本尚未证明值得 |
| 固定旧五币的新数据诊断 | 采用；名单在旧研究中已明确，早于本次评价区间，避免今天按历史收益挑选；只回答这份名单上的问题 |
| 动态退出、扩大币数或参数搜索 | 均延后；否则无法判断改变来自信号本身还是新自由度 |

正结果最多改变“是否提议一项独立验证”的资源决定；负结果可以停止这两个固定规格在本范围内的继续开发。若真正目标必须是中小山寨币机会，则本实验不适用，应暂停而不是用五币结果代替全市场答案。

### 1.1 机制假设与声明等级

- `volume_spike_1h`：异常成交活动可能伴随信息或订单需求的持续消化，因而存在后续收益结构；但成交放大本身没有方向，**做多有优势是待证假设**，也可能反映恐慌或短时流动性冲击。
- `relative_strength_vs_btc`：相对 BTC 的短期走强可能反映尚未完全消化的资产特定需求；但也可能只是高 beta、短期反转或共同市场风险。本轮检验现货单边做多参考收益，不建立 BTC 空头腿。
- 无证据识别付款方、机构吸筹或可持续错价。最多支持限定的 `phenomenon_claim`；`statistical_edge_claim` 不作确认性推广，`economic_edge_claim` 仅成本情景，`execution_feasibility_claim`、`capital_survival_claim`、`live_permission_claim` 均不成立。

## 4. 候选、时间与参数来源

### 4.1 两候选独立运行，不寻找新参数

每个完整 15m 结束点 `t`，以最近四根完整、连续的 15m bar 计算一小时 quote volume 和开盘至末收盘简单收益 `r1h`；BTC 使用完全相同的时间窗。当前窗不得先写入其历史基准。

| 项目 | 冻结规则与来源 |
| --- | --- |
| 成交量异常 | 当前 1h quote volume / 历史中位数 `>= 3.0`；历史为 `u < t`、`t-u <= 7d` 且 UTC 结束小时与当前相同的完整滚动 1h 窗口，至少 5 条，历史中位数须大于零 |
| 相对走强 | 非 BTC 的 `spread = r1h_alt-r1h_BTC`；历史为同币此前 7d 的完整对齐 spread，至少 48 条；`(spread-median(history))/pstdev(history) >= 1.5`，历史标准差须大于零 |
| 时间规格 | `configured_data_lag_ms = 60000`、`entry_delay_bars = 1`、结果窗为 16 根连续 15m bar；复用当前对应 `EXTERNAL_SIGNAL_STAGE1_3_*` 常量并核对值 |

`3.0`、`1.5`、7d、最少 5/48 条、15m、4h、60s 均是**已有规格的固定比较条件**，不是已获理论或数据支持的最优参数。5 条不是 5 个不同历史日，48 条也不是 48 个独立机会；历史滚动窗口可以重叠，包含当日较早且当时可得的窗口。本轮明确保留该实现口径，不暗改成“前七个完整自然日”。

历史不足、标准差/中位数不可用时记不可估计，不填零、不用 epsilon，不触发事件。只保留这两个候选；不执行旧的组合候选和 `price_move_15m` 支线。

### 4.2 时间因果与非重叠观察

`available_at = t + 60000`。入场参考取严格晚于 available_at 的第一根 15m bar 的 open；结果取其后第 16 根 bar 的 close。例如窗口在 12:00 结束，12:01 才假定可得，最早参考入场为 12:15，四小时终点为 16:15。不是在已经结束的 bar 上成交。

每个候选、每个币按 available_at 升序独立处理：从接纳事件时开始占用至其结果窗结束；期间后续触发记 `overlap_suppressed`，不另开观察，结束后才允许接纳下一次。这个规则只减少重复暴露，不是止损或经过优化的冷却参数。两候选不能被拼成共享资金组合。

非重叠接纳和下述分块边界是本单的新观察抽样契约，与旧的逐 15m 触发分母不同；不得拿本轮计数复原、校准或替换旧 summary 的事件数。

将评价区间固定切成从 2026-06-15 零点起的 23 个连续 UTC 7d 块；结果窗不得越过所属块右边界，越界记 `block_boundary_censored`。无信号的块也保留。过滤顺序为完整输入与特征 -> 预定边界资格 -> 触发 -> 非重叠接纳；不得先看未来收益再决定过滤顺序。

## 5. 简单基准、估计量与依赖处理

### 5.1 唯一比较基准

对候选 k 的每个已接纳事件 i，对照集合 C_i 是：**同交易对、同 7d 块、同 UTC available_at 小时、同自身 r1h 符号、同 BTC r1h 符号**的其他合格 15m 决策点，且当点不触发 k、按 k 的已接纳历史观察在该点没有占用。

符号取负/零/正三类，零是自然方向边界，不是收益优化门槛。对照不再要求其他候选不触发，也不因其未来发生新信号而剔除；否则会用未来事件筛选对照。时间/特征/结果窗完整性与边界规则相同，不按未来收益选点。

C_i 使用全部合格点等权，不随机挑赢家，不跨块、放宽小时、合并符号或近邻回退。单个对照可被多个事件使用，对照路径也可相互重叠，须保存并披露这种重复，不能把它们当作额外独立机会或可同时交易的基准组合。对照可以位于事件之后；这是回顾性状态对照，不是决策时可调用的预测器。

若 C_i 为空，记录 `unmatched_control`，保留该事件的绝对收益，不把无对照记成零。本轮同时报告全体接纳事件与可匹配子集；任何未匹配事件存在时，配对结果仅描述该子集，不能据此将全候选标为支持或擅定匹配率通过阈值。

此基准只控制短期时间环境与过去收益方向，**没有匹配价格变化幅度、波动率、beta 或完整市场状态**。因此结果不是“超越一切普通动量/波动指标的独立 Alpha”；本轮不为升级声明增加回归、匹配模型或更多分组。

### 5.2 主估计量与不确定性

对每个候选分别计算，单位 bps：

```text
y_i = 10000 * (exit_close_i / entry_open_i - 1)
mu_gross = mean(y_i over all admitted events)
d_i = y_i - mean(y_j for j in C_i)
delta = mean(d_i over matched admitted events)
mu_scenario(c) = mu_gross - c
```

每个接纳事件权重相等，不以高收益币或高波动事件加权。另报告逐币均值和逐块贡献；不将等权事件平均冒充按资金约束运行的组合收益。候选与对照扣同一个常数 c 时，delta 不变，**正 delta 不等于成本后赚钱**。

依赖/推断单元为所有币共同的 7d 市场块：同时保留该块内全部事件、对照和两个候选，再联合有放回抽取 23 块，重算分子分母，固定 10000 次、seed `20261123`，报告 mu_gross 和 delta 的 2.5%/97.5% 分位区间。空分母记该次不可估计并披露次数，不填零、不补抽；存在这类复制时不得据仅有的有效复制将区间判为完整合格，正向分流阻断。

7d 是在有限区间内吸收同币重叠及跨币共同行情依赖的**近似工作假设**，不是已证明的市场独立周期；最多 23 个观察块，不声称原始事件数就是有效独立样本数。报告每块计数、贡献序列及相邻块依赖风险。区间是探索性、逐项名义区间，不宣称两个候选共同通过了 95% 确认性检验；不输出以行数为样本量的 t 检验。

固定诊断为：按时间前 11 块/后 12 块分别报告均值；逐一去掉一个币或一个块重算均值与 delta；报告 top-1、top-3、top-10% 正贡献及去掉最佳接纳事件的结果。

正贡献统计中，`n` 固定为该候选**全部接纳事件数**；只将 `y_i > 0` 的 gross 收益按降序组成序列 P，记正收益事件数为 m。top-1、top-3、top-10% 对应 `K = 1、3、ceil(0.1*n)`，分子为 P 中前 `min(K,m)` 项之和，分母为全部正收益之和；零收益和负收益永不进入分子。若 m=0（含 n=0），三项比例均为 null，不记为零。例如 10 个事件为 `[+100, -20, -20, -20, -20, -20, -20, -20, -20, -20] bps` 时，n=10、m=1，三项正贡献比例均为 `100/100 = 100%`，不得计算出 top-3=60%。

剔除只对已冻结账本重计，不重新检测或补入原被抑制事件。这些只披露依赖性，不能把剔除后版本当成新策略；两半均为已暴露探索区间，不称独立样本外。

## 6. 成本、路径与经济边界

使用 `cost_context_only`：主结果为参考价 gross 收益，另固定报告已有 `30/50/80 bps` 往返成本情景及盈亏平衡成本 `c_break_even = mu_gross`。这些是历史比较/压力情景，不是本账户真实费率、完整滑点测量或可信上界；不根据结果选择一个成本宣传为“净盈利”。不新增经济通过门槛。

`minimum_economically_meaningful_gain = null`：尚无目标单笔金额、实际 spread/depth 和收益金额目标的联合证据，不能凭空定“至少 N bps”。正结果只能支持继续核算独立验证的价值，不能认定经济有效。若 gross 均值非正，非负摩擦不会将其变正；若仅低成本情景为正，成本问题仍未解决。

报告 gross 及三个情景的均值、中位数、胜率、平均赢/亏、盈亏比、P05/P10/P25/P50/P75/P90、最差事件、逐币/块相关亏损；连续亏损长度按各候选各币的 available_at 序列分别统计，不跨币人为拼接。分位数统一用线性插值 `h=(n-1)*p`；空集或无亏损导致比值不可定义时为 null，不为 0 或 infinity。

复用四小时窗口的 high/low 计算 gross MAE/MFE，明确它们不提供同根 bar 内先后顺序，不是可成交的止损或最大获利。无资金分配与并发组合，本轮组合净值、真实最大回撤、容量、清算距离均 N/A；现货无杠杆、借币、资金费及套保腿。普通亏损包括追涨后反转，尾部风险包括价格跳跃、交易暂停、无法按参考终点成交。

## 8. 结果分流与停止条件

三个维度分开记录：`observation_label`、`resource_decision`、L2 `alpha_research_status`，不拿工程完成当 Alpha 通过。以下按自上而下的**首个命中条件**分流：先检查证据及可估计性，再检查匹配范围，最后判断均值/增量符号与稳定性；null 不当作零或负数。

| 观察条件（逐候选） | 本轮分流 |
| --- | --- |
| 数据/时点/预算/工程前提不成立，或 mu_gross / delta 不可估计（包括无接纳事件、无匹配事件） | `not_estimable / stop_due_to_evidence_or_cost`；保留可估计部分，不能将其余缺口归为没有增量 |
| mu_gross、delta 均可估计，但仍有未匹配事件 | `inconclusive_or_concentrated / pause_for_new_evidence`；只描述匹配子集的 delta，不据子集符号给全候选贴正/负增量标签 |
| 全事件可匹配且 delta <= 0，不论 mu_gross 符号 | `no_increment_observed / stop_fixed_candidate_this_round`；仅指未观察到相对本对照的正样本均值增量，不证明总体无效 |
| 全事件可匹配，delta > 0 且 mu_gross <= 0 | `relative_increment_without_positive_gross / stop_fixed_candidate_this_round`；记录相对增量为正，但绝对做多参考均值不为正 |
| 全事件可匹配，mu_gross、delta 均为正，但不满足下一行完整正向条件（如区间不可估计或下界不大于零、两半方向冲突、单币/单块剔除不稳定或少数事件依赖） | `inconclusive_or_concentrated / pause_for_new_evidence`；不得用最优子集推广 |
| 全事件可匹配，mu_gross 与 delta 的区间下界均大于零；两半均为正，逐币/逐块剔除不翻转主方向，且没有未解释的数据/依赖问题 | `bounded_positive_pattern / consider_independent_validation_only`；最多称本限定现象得到探索性支持，不是确认性显著或经济通过 |

以下是须纳入后续合成验证的分流边界，不是真实收益证据。前三行假定证据有效且全事件可匹配，第四行假定没有可匹配事件：

| mu_gross（bps） | delta（bps） | observation_label | resource_decision |
| --- | --- | --- | --- |
| -20 | +50 | `relative_increment_without_positive_gross` | `stop_fixed_candidate_this_round` |
| +20 | -50 | `no_increment_observed` | `stop_fixed_candidate_this_round` |
| -20 | -50 | `no_increment_observed` | `stop_fixed_candidate_this_round` |
| -20 | null | `not_estimable` | `stop_due_to_evidence_or_cost` |

其中“主方向”同时指 mu_gross 和 delta；两个候选分别完整报告，不以只公开胜出者规避多重尝试。所有停止/暂停均不自动授权改阈值、退出、币池或反手做空。正向分流仍须结合成本情景、尾损和完整工程投入判断是否值得提出下一单，没有自动继续权限。预算停止不是科学证伪；本轮不以 `falsified` 宣告全市场理论失败。

无论哪种分流，广义 Alpha 状态均保留 `evidence_insufficient`，除非未来另获批准的独立、成本/执行研究提供新证据。旧 Factor Lab 纯价格 CMOM、H1 S1、D2 和旧 R10 状态均原样保留。
