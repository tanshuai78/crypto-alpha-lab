## 0. 执行摘要

本文保留的研究母问题（不是全部首轮目标），不是“什么 K 线形态容易上涨”，而是：

> **为什么相同的主动买卖成交压力会在不同状态下造成不同的价格影响？价格冲击的变化能否在决策时点被识别，并对未来收益、尾部风险或首次触及风险屏障的路径产生独立预测增量？**

VCP（Volatility Contraction Pattern，波动收缩形态）提供了“卖压逐渐减弱、波动收缩、随后由新增需求推动”的直觉。但若只把它翻译成“缩量 + 波动下降 = 看涨”，就极易把新币开盘后的自然冷却、买卖双方同时离场、以及薄盘口误判为卖压吸收。

以下外部理论用于查阅，不是八项待开发任务：

1. **Kyle / Hasbrouck 价格冲击与交易信息理论**：为 A0 提供可估计的价格—主动成交关系。
2. **Wyckoff Effort vs Result（努力与结果）**：提出“相似卖压下跌幅趋弱”的可证伪经济假设，比直接复刻 VCP 图形更适合加密逐笔成交数据。
3. **Bouchaud / Farmer / Lillo 订单流记忆与冲击衰减**：区分持续性冲击、暂时性冲击和后续价格反转。
4. **Cont / Kukanov / Stoikov 订单簿 OFI（Order Flow Imbalance）**：检验成交压力变化背后的挂单、撤单与流动性恢复机制，优先级稍后。
5. **CUSUM / Change-point（统计过程变点检测）**：识别价格冲击机制由“易跌”转向“不易跌”是否有提前量。
6. **Survival Analysis / Competing Risks（生存分析与竞争风险）**：衡量价格路径先触及正向目标还是风险屏障，而非只看终点收益。
7. **Volume Time（成交量时间）**：检验固定时钟下的“收缩”是否仅由活动量自然衰退造成。
8. **事件研究 / 反事实对照 / 样本外验证**：把“解释同期价格的现象”与“预测未来的交易优势”严格分开。

**2026-11-19 取舍：只建议先预审 H1，暂存 H2，其余方法按需后置。**原来的多特征 M0/M1/M2、固定时窗及六步开发议程不再作为当前实施建议；本稿未运行预审或实验。D2 仍按[原备忘录 §6](../reviews/2026-11-12-launch-event-data-research-directions-discussion_CN.md#6-当前决定与工作交接)暂停，不能误称为仍有执行优先级。

**H1 与原 A 的关系：**原 A 已问“持续卖压下为何越来越跌不动”；H1 只是收缩为卖方一侧的条件交互问题，不是新发现。候选检验为：在控制历史价格路径、活跃度、波动及普通成交失衡后，持续净卖压下的下行响应减弱，是否对应更高的后续收益。收益更高不等于为正或成本后盈利；收益而非风险作为首个目标仍是建议，尚未批准。

**阅读导航：**§1 核对历史依据，§2 看保留/暂存的方法，§3–§7 查理论与数据限制，§8–§10 看尚待批准的最小检验边界与推进顺序。参数依据原则见[备忘录 §4.1](../reviews/2026-11-12-launch-event-data-research-directions-discussion_CN.md#41-参数依据与实验固定不是一回事2026-11-19)，本轮决策见[备忘录 §6.4](../reviews/2026-11-12-launch-event-data-research-directions-discussion_CN.md#64-vcp-与跨领域讨论后的取舍及下一步2026-11-19)。

## 3. 核心理论一：Wyckoff 的 Effort vs Result

### 3.1 原理

Wyckoff 强调成交活动（Effort，努力）与价格推进幅度（Result，结果）的关系；两者不匹配可用来提出承接、供需失衡或衰竭假设。Wyckoff 原版还有积累/派发区、Spring 等图形概念，但其中主观识别很难直接重现，应暂时排除。[1]

VCP 注重**卖压与波动是否收缩**；Wyckoff 则让我们进一步问：**即便卖方继续成交，价格为何越来越难下跌？**

### 3.2 量化假设

例如三个连续窗口（示意，非实测）：

| 窗口 | 主动净卖出额 | 同期收益 |
|---|---:|---:|
| W1 | 500,000 USDT | −2.0% |
| W2 | 480,000 USDT | −0.7% |
| W3 | 520,000 USDT | −0.1% |

在净卖压相近时跌幅下降，值得研究**条件价格冲击是否减弱**，但不能由此断言“大资金吸筹”。可能的替代解释包括：全市场波动下降、外部相关资产上涨、交易时间变化、盘口恢复或偶然价格跳动。

**H1（原稿 H-W，属备忘录 A 的子问题）**：持续净卖压下的下行响应减弱，是否在充分旧变量基准外对应更高的后续收益。原稿同时提出的固定 15 分钟、收益或风险双目标不再作为首轮既定条件；未来需明确一个主要目标和有理由的窗口，不能在结果不利时切换通过标准。

**反假设**：条件跌幅变小只是自然交易冷却造成，未来收益/风险没有稳定变化。

### 3.3 不建议照搬的部分

不引入纯人工定义的吸筹/派发阶段、复杂波段识别、Spring/Shakeout、静态支撑阻力和主观“聪明钱意图”。真正研究对象是可复现的**压力—价格响应**关系。

## 4. 核心理论二：Kyle / Hasbrouck 的价格冲击与信息含量

### 4.1 原理与适配

Kyle（1985）研究在订单流包含信息时如何形成价格；Hasbrouck（1991）以成交和报价的动态关系估计交易的信息含量。[2][3]

为研究方便，可以先采用一个**简化统计代理**：

\[
 r_t = \alpha + \lambda Q_t + \beta^\top X_t + \varepsilon_t
\]

其中：

- \(r_t\)：时窗价格变化（优先中间价；数据不足时清晰标注为成交价变化）；
- \(Q_t\)：主动买入额减主动卖出额的净名义成交额；
- \(X_t\)：总成交额、历史波动、近期趋势、产品机制等预定控制量；
- \(\lambda\)：条件价格冲击的**经验代理系数**，**不等于** Kyle 模型的结构参数；
- \(\varepsilon_t\)：不能被简单成交压力模型解释的价格变化。

最值得追问的不是“\(\lambda\) 是否显著”，而是：

1. 在相近净卖压下，\(\lambda\) 或残差结构是否发生稳定变化？
2. 变化出现在价格反转之前，还是只是跟随已发生的价格变化？
3. 这些变化在独立 Parent、不同上市机制和样本外是否保留对**未来**结果的预测力？

**代数边界：**若同一训练折的系数固定，`e_t = r_t - alpha - lambda * Q_t - beta * X_t` 只是 `r_t/Q_t/X_t` 的线性组合。如果相同分窗变量已在基准中，加入该残差或其线性差分不会扩展线性特征空间；若因此“改善”，先检查是否基准漏了价格信息或训练比较不公平。非线性交互可以增加模型表达能力，但不等于增加了新原始信息或证明因果承接。

### 4.2 可区分的候选机制

- **Pressure continuation（压力持续）**：连续主动买压具有后续同向价格影响。
- **Pressure reversal（压力反转）**：当期冲击较大但迅速消退，随后出现反向价格变化。
- **Absorption（承接改善代理）**：当期持续净卖压对应的下跌响应下降，后续损失分布改善。

三者应分别报告；不允许统一解释为“逢缩量做多”。

### 4.3 主要风险

- 同期的订单流和价格相互影响：**当期回归有解释力不等于能预测未来**。
- 低成交窗口使“价格变化 / 交易额”比率不稳定；不采用无下限分母的简单比率。
- 高波动与低流动性区间，线性 \(\lambda\) 容易失真；先做同机制、同活跃度条件比较，再考虑非线性。
- 最优成交价序列可能因 bid–ask bounce（买卖价差引起的成交价跳动）产生假冲击；如缺乏同步中间价，必须报告这一识别限制。

## 5. 核心理论三：Bouchaud 的订单流记忆与冲击衰减

订单流可以呈现持续的主动买入/卖出，而流动性供给会动态变化，价格冲击因而可能具有暂时性与持久性成分。[4]

**H2（原稿 H-I，当前暂存）**：相同方向成交压力下，过去可观测的近期响应持续/衰减状态，是否预测后续方向或风险路径。本轮不拟合多个衰减时距；下述内容保留为后备理论，不是执行任务。

后续若单独研究 H2，可在事先明确的观察时点 \(t\)，对一个压力状态估计后续响应：

\[
 R(h \mid \mathcal{F}_t) = \mathbb{E}[\log P_{t+h}-\log P_t \mid \text{已知压力状态及控制量}]
\]

这里 \(h\) 可以是 1、5、15、30 分钟等**预注册的诊断时距**；不能通过挑选最有利的 \(h\) 宣称策略通过。

重要对照：

- 高主动买入 + 后续价格继续上涨：候选持续冲击。
- 高主动买入 + 价格快速回落：候选暂时冲击/反转。
- 高主动卖出 + 跌幅变小：候选卖压吸收/市场承接，但须排除总活动下降。

**原则**：未来价格只能作为标签，不得进入 \(\mathcal{F}_t\) 的特征；若用未来价格拟合冲击曲线，再反过来声称能在 \(t\) 识别状态，就是前视偏差。

## 6. 其他五种理论 / 方法的作用边界

### 6.1 Cont 的 OFI：成交量并不是完整供需

OFI（订单簿事件失衡）考虑市价单、限价挂单、撤单等对盘口最优报价的影响；相关研究在股票样本中发现其与短期价格变化的显著关系。[5]

三个容易混淆的状态：

| 已成交数据 | 订单簿可能发生的事 | 对研究的启示 |
|---|---|---|
| 主动卖出仍多、价格稳定 | 买盘补充、流动性吸收 | 候选承接改善 |
| 主动买卖同时下降、价格稳定 | 买卖双方都退出 | 不应自动视为吸筹 |
| 净买入有限、价格快速上涨 | 卖方撤单、盘口变薄 | 不能直接解释为买盘特别强 |

**数据约束**：历史 `aggTrades` 不含完整挂撤单。Stage 1.5F 的离散盘口快照也不能重建逐事件 OFI。先审查时间粒度、丢帧和订单簿连续性，再考虑独立 OFI 研究；不得仅凭 `aggTrades` 字段声称已测得 OFI。

### 6.2 CUSUM / Change-point：检测冲击机制变化

CUSUM（累积和控制图）是工业统计的顺序变点检测工具，经典来源为 Page（1954）。[6]

应用方式不是再次寻找价格波动突破，而是检测：**价格对卖压的条件响应系数、残差或响应状态是否出现超出正常噪声的持续变化**。

建议顺序：先由 A0 证明响应指标可稳定估计 → 再在训练集校准 CUSUM → 用样本外报告平均告警延迟、误报率及告警之后的风险路径。

项目现有 [`cusum.py`](../../src/research/external_signal_shadow/cusum.py)处理 K 线收盘对数收益，不是可直接作用于冲击系数残差的公开接口。只能先参考思想、核查适配边界，不能把存在该文件当作已完成复用。**本轮后置，变点检测不自动成为交易信号。**

### 6.3 Competing Risks：路径先后比终点收益更重要

生存分析/竞争风险分析用于研究多个相互排斥的首次事件哪个先发生；可先使用简单的经验累计发生率，无须立即引入复杂的 Cox 或 Fine–Gray 回归。[7]

追溯 J-C 的旧场景时，实际协议为：

- 事件 A：先触及 +3000 bps 正向诊断屏障；
- 事件 B：先触及 -200 bps 不利诊断屏障；
- 窗口结束未触及：不是第三种竞争触及事件，而是该观察期限内未发生触及。

这些只是旧协议的场景值，不是 H1 默认值或合理性证明。更换决策时点、方向、持有终点或价格基准后不能声称直接可比；无须为首轮检验任意设置一对屏障。

后续风险诊断可以问：候选状态是否改变“首先触及不利屏障”的条件概率、触及时间及最大不利变动（MAE）？它不是当前 H1 的额外主要目标；终点价格为正也不证明路径可交易。

### 6.4 Volume Time：避免把自然冷却当 Alpha

按固定时钟（例如三段 15 分钟）构造特征，在新币开盘后会受到成交额急剧变化的影响。Volume Time 改用累计相近成交额形成窗口，可帮助区分成交活动变化与价格冲击机制变化。[8]

**最重要的反证**：如果 A1 的“收缩预测力”在固定时钟窗中明显，但对齐到相近成交活动规模后消失，则应怀疑它主要刻画自然交易冷却，而非独立承接能力。

Volume Time 仍须严格执行 **PIT（决策时点可得性）**：生成当前窗口所用成交量阈值只能来自当时之前的训练信息；不可用全天总成交量或未来结束时刻反推历史窗口。未来价格结果继续以真实时钟计算，不必与事件时间混用。

它改变了窗口实际持续时间和样本权重，因此效果消失不是对 H1 的最终裁决。逐笔随机置乱方向也会破坏时间持续性及其与价格、金额的联合结构；即使作为辅助负对照，也不能以“不显著”直接证明机制不存在。本轮不为这些方法另建工程。

### 6.5 事件研究 / 反事实对照：判断新增解释力

必须避免两种假阳性：

1. “VCP 信号”全部由此前价格已经上涨或波动已经下降解释。
2. 一两个极端 Parent 产生整个样本看似显著的收益。

因此必须比较相同合格事件、相同决策时点和相同未来结果的嵌套模型。统计方法不是锦上添花，而是决定该理论能否进入下一阶段的必需条件。

这里检验的是预测增量，不是已识别的因果效应；当前未定义可支持因果解释的处理、对照及识别假设。

## 7. 数据：我们能观测什么，不能观测什么

### 7.1 Binance `aggTrades` 已支持的观测

Binance USDⓈ-M 的聚合成交归档包含价格、数量、聚合成交 ID、时间以及 `Was the buyer the maker` 等字段；其中 `buyer_is_maker=True` 可用于推断**卖方为主动成交方**，`False` 推断**买方为主动成交方**。具体按该产品数据格式及归档 schema 校验。[9]

令一笔聚合成交名义额 \(V_j=p_j q_j\)（单位为 USDT 或对应计价资产单位；需按合约类型确认），主动方向 \(s_j=+1\) 表示主动买入，\(s_j=-1\) 表示主动卖出：

\[
Q_t=\sum_{j\in t}s_j V_j,\qquad
V_t=\sum_{j\in t}V_j,\qquad
I_t=Q_t/V_t
\]

其中：

- \(Q_t\)：窗口净主动成交额；
- \(V_t\)：窗口主动成交总额；
- \(I_t\)：成交失衡比例（\([-1,1]\)）；
- 可进一步分别记录买方和卖方主动成交额、成交笔数、成交价变化、收益与实现波动。

**拒绝规则**：零成交或低于预先规定的可估计性下限时，指标置为“不可估计”，不得用任意微小分母硬算一个巨大冲击值。

若 `B` 为相同窗口、相同成交额口径的主动买入占比，则卖方占比 `S=1-B`、`I=2B-1`。已有[主动买入占比研究](../designs/2026-10-31-launch-taker-buy-share-residual-response-exploratory-design_CN.md)及[实现](../../src/research/external_signal_shadow/launch_taker_buy_share_residual_response.py)已使用 `is_buyer_maker`；改变符号或名称不是新因子。占比下降也不意味着绝对卖出额下降，须区分总活动变化。

### 7.2 数据不支持的结论

`aggTrades` 不能直接提供：完整挂单/撤单、隐藏流动性、交易参与者身份、真实大户吸筹意图、从信号出现到订单成交的可执行价格，也不能单独给出完整的 top-of-book OFI。

相邻异向成交的价格差混合了价差、中间价变化、时间间隔和成交深度，只能作为噪声代理，不能直接称为实测点差或往返成本。整体中位价格空间偏小可以影响资源判断，但不能排除少量事前可识别状态；整体 MFE 很大也不证明能捕获盈利。

历史日度归档可重放过去已发生的行情，但**历史归档的发布时间与回测特征当时可计算的市场信息是两回事**。回测必须遵守：单笔成交时间戳不晚于信号决策时刻；历史取得/缺口/重建方法留存；若未来正式实时化，还须验证真实数据传输延迟与实时观测可用性。

### 7.3 待授权的可估计性预审

对每个 Parent / symbol / listing regime 报告：

- 官方上线时间及首笔成交时间 \(T_0\) 的来源与质量；
- 数据 ZIP 身份、哈希、日期覆盖、解析完整性、时间戳排序和重复聚合成交 ID；
- 研究主窗口是否完整；未来标签窗口是否完整；
- 无成交/异常值/交易中断/价格精度问题；
- Parent 及同批上市子合约关系；
- Stage 1.5J-A 与 J-B 既有 receipt 的身份可重用性及限制；
- 该行 `eligible` / `excluded` / `insufficient` 的确切原因。

覆盖核验不等于收益研究。预审只核查来源、字段、时钟与序列、必要的特征窗活跃度和可比压力范围，不计算未来收益、MAE/MFE、收益排序或训练模型。候选时窗及查看范围先写明理由，不按未来表现选窗；进入实际原始数据读取仍须满足上游身份及消费授权。未来标签可用性可查时间/记录覆盖，不据此偷看价格结果。

## 8. 最小 H1 检验应明确的边界（未获批）

### 8.1 参数没有定案

原稿提出过 `60m` 形成、后续 `15m`、`3s` 延迟和另一组三段 `5m` 窗口。这些只是历史候选，没有数据或理论证明它们最优，本次不继承为主实验或默认敏感性网格。先按机制、数据粒度、可估计性和资源说明候选依据；不先查看未来收益再选择最好窗口。

区分示例、探索性候选、单次实验固定值与经验证参数。实验固定用于复现和防后见之明，不使参数永久正确；有新认识可以修改，但保留旧版本、结果与选择过程，将调整后的研究继续标为探索。预注册的存在不能消除旧样本已经暴露的事实。

### 8.2 只建议比较两个模型

| 比较 | 候选输入与限制 |
| --- | --- |
| 充分但低维的基准 | 同等时间分辨率的历史收益/价格减速、波动、成交活跃度和普通成交失衡；精确定义待预审后确定 |
| 唯一扩展 | 基准加一个事前定义的“卖压持续 × 下行响应减弱”交互，不同时加入线性残差、多个衰减速度和 VCP 打分 |

两者使用相同有效 Parent、时点、标签和训练预算；所有系数、标准化、分组或阈值只能在训练部分确定。若公平比较必须控制的维度超过样本可承载范围，暂停而非削弱基准。交互的确切公式及其复杂度仍须论证，本文不指定任意阈值。

### 8.3 一个主要目标，诊断不能顶替通过标准

当前建议以更高的后续收益为候选主问题，预先明确预测损失及 Parent 等权比较；这属于问题聚焦，不是“收益一定可预测”的证据。MAE/MFE、尾部、方向、屏障和多个预测时距不能轮流成为通过标准。若选择风险而非收益作为主要目标，须在看结果前明确，不因收益失败临时更换。

旧样本结果只能支持探索性取舍。未来价格空间与噪声诊断一旦计算未来收益或路径，就属于结果探索，应先明确实验与适用授权，不能藏在纯覆盖预审里。成交价路径不是可执行价格，不输出伪精确净 PnL。

## 9. 研究设计中必须抵御的失败模式

| 风险 | 可达错误结论 | 最小保护 |
|---|---|---|
| 同期相关误作预测 | 订单流解释同一时段价格就被称为预测未来 | 特征/标签时间严格分离 |
| Parent 子标的与重叠窗口重复计数 | 虚增独立样本数和显著性 | Parent 级分组、聚类统计、不得跨 train/test |
| 上市机制混合 | 成熟标准合约稀释 TradFi/Pre-Market 的摩擦 | 按机制分层、报告各自样本量 |
| 价格/成交量收缩只是冷却 | 把全市场参与者撤离误判为吸筹 | 先控制活跃度与分窗价格，Volume Time 仅在确有必要时另评估 |
| 仅由 1–2 个暴涨 Parent 拉升 | 均值好看但实际机会不稳 | Leave-one-parent-out、Parent 贡献、分位数 |
| 挑选最好的窗口/阈值 | 后视参数挖掘 | 冻结主窗口和候选假设；探索与验证分离 |
| 价格冲击的机械噪声 | 买卖价差、报价跳变当成冲击 | 有中间价时复核；没有则标明限制 |
| 原始归档覆盖偏差 | 只保留行情存在的标的 | 显式列出所有 Parent 缺口与排除原因 |
| 数据归档发布时间被混同为市场事件时间 | 假装实时系统可在当时看到未来下载的归档 | PIT 重放；未来实时可用性单独证明 |
| 把预测改进当净收益 | 交易成本/深度/尾部损失吞噬优势 | 分离统计、经济、执行、资本生存声明 |

**独立机会**：以上市父公告 `parent_article_id` 作为默认统计单位；不同子标的可作为诊断子观察，不可独立计数。同一个 Parent 不跨训练/保留集，日历上同批密集公告需另评估残余相关性。

**分割**：按时间顺序冻结开发/保留集，避免交叠观察窗泄漏；报告有效 Parent 数量和每个机制的分布。若独立样本过少，不强迫给出显著或否定性结论；按 `evidence_insufficient` 处理。

旧事件已经影响问题与特征选择时，上述保留集仍不是全新确认集；不得以重新切分、重复留一或增加 child/window 行数恢复独立确认资格。

**先验预注册**：决定主窗口、收益标签、基准模型、误差度量、最小有意义增量、统计不确定性判据、异常值处理和停止条件后，才能查看主结果。不能根据结果把“最优的一个参数”重新称为预注册结论。

## 10. 建议推进顺序与停止边界（未执行）

原六步开发路线已撤下，改为四个有退出条件的环节；本轮只更新本文及备忘录，不启动下述数据操作。

| 顺序 | 最小交付与范围 | 继续或暂停 |
| --- | --- | --- |
| 1. 可估计性预审 | 先写简短方案并明确授权来源/字段、候选查看时窗及理由；按 §7.3 核对有效 Parent、活动与压力可比性、旧特征和复用接口，交一份人工报告 | 预算建议最多半个工作日，含核验与报告；到点交付缺口，不自动下载、扩样或建管道。这是资源上限，不是科学阈值或交付承诺 |
| 2. 最小实验定义 | 预审可行才明确一个主要假设、目标、窗口依据、低维基准、唯一交互、损失、不确定性和停止条件；估算实现/测试/评审/重跑总成本 | 按适用 L1/L2 起草并审批 Design/Plan 和上游消费/运行范围；不以仓外脚本或“离线”跳过研究语义与授权 |
| 3. 一次获批探索 | 在同集合上执行 §8 的比较，保留全部缺口、版本、失败和异常值依赖；未来收益/路径分析在此阶段声明 | 不因不利结果改窗口、换主要指标或删事件，不用未来数据拟合当前特征 |
| 4. 资源分流 | 根据效果大小与精度区分探索性增量、可排除的无有意义增量和证据不足 | 正向只支持评估独立新事件验证；预算/性价比不足可暂停，不冒称机制已被证伪 |

若必要控制无法在样本规模内稳定估计，停止这个检验，不硬凑模型。少量旧样本上的不显著不能直接支持 `no_material_increment`；需要精度足以排除预先说明的有意义增量，否则是 `evidence_insufficient`。

不默认建立完整 Rule 17 收据体系、独立 Verifier 或新 Stage；按产物实际后果配置验证，同时保留既有上游 profile、身份与消费边界。后续交易可行性另验费用、报价差、冲击、资金费、容量、延迟和损失路径；不授权任何下单或 VPS 操作。

## 11. 暂时不做的事与机会成本

- **不开发完整 VCP/Wyckoff 图形识别器**：多次回调、Spring、突破 pivot、50/200 日均线等参数增加自由度，但未提供独立机制证据。
- **不做“指标越多越好”的共振打分**：动量、均线、创新高常是同一信息的重复包装。
- **不把 OFI 当成已有数据能力**：缺完整挂单/撤单事件数据时不得伪造订单簿冲击。
- **不马上上机器学习大模型预测涨跌**：先用简单基准回答数据是否真正包含增量信息。
- **不新开实盘交易或延伸 VPS 权限**：现有采集系统保持独立，离线研究不应干扰真实公告数据链。
- **不重新开放已证伪的无条件追涨方向**：新候选假设必须具有清晰不同的可观察机制。

## 12. 后续讨论只解决三个问题

1. 必要的成交序列、可比压力范围和独立 Parent 是否足以支持低维公平比较？不能只回答“归档文件存在”。
2. 唯一交互与旧价格/成交方向变量究竟有何区别，怎样避免线性冗余、微观噪声和过多自由度？
3. 哪一项结果会改变继续投入的决定，预算是多少，证据不足时能否接受暂停？

不预先设置五个 Agent 的全套分工或追加八类理论任务；只对会改变决定的实质缺口做适度独立复核，按项目适用评审流程推进。
